**Class Name:** PasswordManager  
**Function Name:** hash_password  
**Description:** This function hashes a password.  
**Parameters:**  
- password: The password to be hashed.  
**Returns:** The hashed password.  
**Exceptions:** None  

**Function Name:** check_password  
**Description:** This function checks if a password matches a hashed value.  
**Parameters:**  
- password: The password to be checked.  
- hash_val: The hashed value to be checked against.  
**Returns:** True if the password matches the hashed value, False otherwise.  
**Exceptions:** None  

**Function Name:** is_strong_password  
**Description:** This function checks if a password is strong enough.  
**Parameters:**  
- password: The password to be checked.  
**Returns:** True if the password is strong enough, False otherwise.  
**Exceptions:** None
