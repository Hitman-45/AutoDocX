**Class Name:** UserService  
**Function Name:** login  
**Description:** This function checks if the provided username and password match the expected values.  
**Parameters:**  
- username: the username to be checked.  
- password: the password to be checked.  
**Returns:** true if the username and password match the expected values, false otherwise.  
**Exceptions:** None.  

**Function Name:** getUserRole  
**Description:** This function returns the role of the user based on their username.  
**Parameters:**  
- username: the username of the user.  
**Returns:** the role of the user.  
**Exceptions:** None.  

**Function Name:** logout  
**Description:** This function logs out the user by printing a message to the console.  
**Parameters:**  
- username: the username of the user.  
**Returns:** None.  
**Exceptions:** None.

Please note that the actual output of the program will depend on the implementation of the `login`, `getUserRole`, and `logout` methods.
