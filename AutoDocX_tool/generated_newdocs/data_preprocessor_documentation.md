**Class Name:** Utils  
**Function Name:** clean_data  
**Description:** This function cleans the data by removing leading and trailing whitespace and converting to lowercase.  
**Parameters:**  
- data: list of strings  
**Returns:** list of cleaned strings  
**Exceptions:** None  

**Function Name:** compute_average  
**Description:** This function computes the average of a list of numbers.  
**Parameters:**  
- numbers: list of numbers  
**Returns:** average of the numbers  
**Exceptions:** None  

**Function Name:** filter_outliers  
**Description:** This function filters out the outliers from a list of numbers. An outlier is a number that is more than 2 standard deviations away from the mean.  
**Parameters:**  
- data: list of numbers  
- threshold: the maximum allowed deviation from the mean (default is 2)  
**Returns:** list of numbers with outliers filtered out  
**Exceptions:** None
